# 💼 Hike Calculator for Corporate Employees

An interactive web-based tool designed to help corporate employees calculate their **salary hike**, understand compensation changes, and estimate future earnings in a simple and user-friendly way.

---

## 🚀 Features

* 📊 Calculate salary hike based on percentage or fixed increment
* 💰 Compare **current vs revised salary**
* 📈 Breakdown of monthly and annual compensation
* 🧮 Easy-to-use and responsive UI
* ⚡ Instant calculations without reload

---

## 🎯 Purpose

As a Technical Support Engineer, I wanted to build a **practical utility tool** that solves a common real-world problem  understanding salary increments clearly.

This project focuses on:

* Simplicity
* Usability
* Real-world relevance
